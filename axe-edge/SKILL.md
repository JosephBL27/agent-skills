## Use subagents selectively

Default to the main agent. Use the installed `axe-tool-scout` only when discovery
is broad, verbose, independent, or likely to pollute the parent context. Use
`axe-resource-master` only after selecting a reusable resource. Keep both
read-only, never nest them, and keep returns under 700 words. Subagents can
reduce parent-context load and latency but increase total token use.
